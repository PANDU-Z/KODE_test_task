# Максим Севостьянов

## Тестовое задание KODE trainee-test-frontend

В рамках данного задания необходимо разработать веб-приложение для просмотра и поиска сотрудников компании.

Приложение должно получать данные из API и отображать список сотрудников с возможностью поиска, фильтрации и сортировки.

---

# Декомпозиция задания

## 1. Подготовка проекта
1. Создать проект на базе **Vite + React + TypeScript**
2. Установить необходимые зависимости:
   - React Router
   - Axios
3. Настроить структуру проекта.

---

## 2. Архитектура проекта
Создать базовую структуру папок:
- src
- api
- components
- pages
- types
- hooks
- utils
- styles

---

## 3. Работа с API
1. Изучить спецификацию API.
2. Реализовать запрос списка сотрудников: GET /users?__example=all
3. Создать типы данных пользователя (User).
4. Реализовать функцию получения списка сотрудников через **Axios**.

---

## 4. Главная страница
1. Реализовать экран со списком сотрудников.
2. Отобразить:
   - аватар
   - имя и фамилию
   - userTag
   - должность
3. Реализовать компонент карточки сотрудника.

---

## 5. Поиск сотрудников
Добавить строку поиска, которая позволяет искать сотрудников по:
- имени
- фамилии
- userTag.

Поиск должен работать в реальном времени.

---

## 6. Фильтрация по департаментам
Реализовать вкладки департаментов.

Возможные значения:

- All
- Android
- iOS
- Design
- Management
- QA
- Back Office
- Frontend
- HR
- PR
- Backend
- Support
- Analytics

При выборе вкладки отображаются сотрудники только выбранного департамента.

---

## 7. Сортировка сотрудников
Добавить сортировку сотрудников:

1. По алфавиту
2. По дате рождения

---

## 8. Страница сотрудника
Реализовать страницу с подробной информацией о сотруднике.

Отобразить:
- аватар
- имя
- userTag
- должность
- дату рождения
- номер телефона.

---

## 9. Обработка состояний интерфейса

Добавить обработку состояний:

### Загрузка
Показывать индикатор загрузки при получении данных.

### Ошибка
Отображать экран ошибки при проблемах с API.

### Пустой список
Показывать сообщение, если сотрудники не найдены.

---

## 10. Финальная проверка
1. Проверить корректность работы:
   - поиска
   - фильтрации
   - сортировки
2. Проверить адаптивность интерфейса.
3. Подготовить финальную версию проекта.

---

# Используемые технологии

- React
- TypeScript
- Vite
- Axios
- React Router

Установка зависимостей: npm install
